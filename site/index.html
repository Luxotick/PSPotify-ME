Install a theme

  1. Download the theme's .zip and unzip it.
  2. Copy its THEMES folder to PSP/GAME/PSPOTIFY/ on the Memory Stick, next to EBOOT.PBP. You end up with PSP/GAME/PSPOTIFY/THEMES/<theme>/theme.ini.
  3. On the PSP, open Settings → Themes and pick it. If the theme has a wallpaper, set Settings → Appearance → Background to Theme wallpaper.

PSPotify ME lists up to 16 themes.

Share your theme

The gallery is the themes/ folder of the PSPotify ME repository. To add yours, open a pull request:

  1. Make the theme in the editor and download it.
  2. Fork the repository on GitHub.
  3. Add the folder from the zip (the one inside THEMES) as themes/<Your theme>/: theme.ini, plus the wallpaper if it has one. You can upload files in the browser with Add file → Upload files.
  4. Open a pull request with a line about the theme.

Please keep it to one folder per theme, a folder name in plain letters and numbers (up to 31), and a wallpaper you made yourself or are free to share, under 2 MB (480×272 is best). Once it is merged, the site rebuilds and the theme shows up here with its own preview.
