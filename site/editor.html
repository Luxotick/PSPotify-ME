Install: unzip and copy the THEMES folder to
        PSP/GAME/PSPOTIFY/ on the Memory Stick, next to EBOOT.PBP,
        so you end up with PSP/GAME/PSPOTIFY/THEMES/My theme/theme.ini.
        Then pick it under Settings → Themes.

      
For the wallpaper, set Settings → Appearance → Background to
        Theme wallpaper.
